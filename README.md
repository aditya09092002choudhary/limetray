# Advanced Task Manager

A React task manager with add/complete/delete, filters, local storage persistence, custom `useLocalStorage` hook, Context API, drag-and-drop (react-beautiful-dnd), light/dark theme, basic CSS animations, and responsive layout.

## Requirements
Node 16+ and npm

## Setup
1. Clone or copy the repo.
2. Run `npm install`.
3. Run `npm start`.

## Scripts
- `npm start` — run development server
- `npm run build` — build production bundle
- `npm test` — run tests (if added)

## Notes
- Install peer packages if needed: `npm install react-beautiful-dnd uuid`
- Theme and tasks persist in localStorage keys `theme_v1` and `tasks_v1`.
